# Practice and rubric

Complete the two original sets independently, then consult `answers.md`. Explain the rejected choices as well as the preferred one. These are study feedback, not real exam questions or a predicted score. Revisit weak topics, choose your own target, and repeat with fresh scenarios rather than memorizing answers.

For each project assess: correctness and boundary cases; error handling and bounded execution; authorization and safe data handling; meaningful deterministic tests; architectural trade-offs; and communication, provenance and uncertainty. Rate each as needs work, developing, or explainable independently. Passing tests alone cannot establish mastery.
