# Sources and maintenance

Reviewed 11 November 2026. Certification content and product behavior can change; check official material before a release. The [community Ravn guide](https://ravnhq.github.io/claude-certified-architect/guides/en.html) provides the domain weights used for study planning. Its scenario counts are inconsistent. [Anthropic's certification announcement](https://www.anthropic.com/news/claude-partner-network) identifies the certification; consult current official objectives and eligibility guidance for exam details. Course questions are original and are not a prediction of exam results.

Review dependency pins, CLI/SDK examples, authentication, supported model IDs, protocol versions and certification objectives before publishing a new release. Record the review date and run offline checks in a clean environment. Live checks require explicit opt-in and appropriate access; document what was actually tested.
